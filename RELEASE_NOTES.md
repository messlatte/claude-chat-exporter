- Fixed: the app sometimes stopped responding right after its window opened.
- Updated dependencies, among them PyInstaller 6.22.3 and pythonnet 3.2.1. The bundled licence texts match the new versions.
- The interface now lives in separate HTML, CSS and JavaScript files inside the app. It looks and works as before.

Files:

- `Claude-Chat-Exporter-1.0.2.exe`: the app, runs without installation. The licence texts are built in and shown under "Lizenzen".
- `Claude-Chat-Exporter-1.0.2-with-licenses.zip`: the same EXE with all licence files.
- `SHA256SUMS.txt`: checksums of both files.

The EXE is not signed, so Windows SmartScreen shows "Unknown publisher". Choose "More info", then "Run anyway" to start it.
